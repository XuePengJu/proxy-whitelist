# ClashMate — 白名单走代理

Chrome MV3 代理插件：**白名单内域名走 Clash 代理**，其余全部直连（不走代理）。

> 与 ProxyMate（白名单走直连）方向相反：ClashMate 用于"默认直连、特定网站走代理"。

## 功能

- **一键开关**：点击图标启用/关闭代理
- **代理配置**：协议固定 SOCKS5、端口固定 7897，代理地址可编辑
- **抓包一键加白名单**：点击「抓取本页接口域名」自动刷新当前页面，10 秒内抓取该页请求的全部域名并自动加入白名单（无需勾选）；也可输入网址打开新标签页抓包
- **抓取期间全局代理**：抓取时临时让所有流量走代理，目标网站不在白名单也能完整打开，抓全域名后自动恢复白名单模式
- **三重模式标识**：页面右上角悬浮标（10 秒倒计时）、图标角标橙色 CAP、弹窗模式状态行
- **规则文件**：`rules/proxy-whitelist.txt`（后缀匹配，编辑保存后重开弹窗即生效）

## 安装

1. 打开 `chrome://extensions/`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本目录（`proxy-whitelist/`）

## 使用

1. 确保本地 Clash 已运行（默认端口 7897）
2. 打开目标网站（如 YouTube）→ 点插件图标 →「抓取本页接口域名」
3. 10 秒后域名自动入白名单 → 刷新页面即可完整访问
4. 网站更新了 CDN/接口域名时，再抓一次补全
